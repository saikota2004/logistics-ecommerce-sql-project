# Logistics & E-commerce Order Management System

A MySQL-based logistics and e-commerce database project designed
to manage and analyze customers, products, orders, payments,
warehouses, inventory, deliveries, returns and suppliers.

## Technologies

- MySQL
- MySQL Workbench
- SQL

## Database Tables

- Customers
- Products
- Orders
- Order Items
- Payments
- Warehouses
- Employees
- Deliveries
- Inventory
- Returns
- Suppliers

## Dataset

- 50 customers
- 30 products
- 600 orders
- 600 payments
- 10 warehouses
- 30 employees
- 600 deliveries
- 300 inventory records
- 10 suppliers
- Returns generated from returned orders

## SQL Concepts

- Primary Keys
- Foreign Keys
- Constraints
- JOINs
- LEFT JOINs
- GROUP BY
- ORDER BY
- Aggregate Functions
- Date Functions
- Subqueries
- Data Validation
- Business Analysis

## Business Analysis

The project includes analysis of:

1. Total orders and revenue
2. Monthly sales performance
3. Top products by revenue
4. Top customers by spending
5. Warehouse performance
6. Delivery performance
7. Payment analysis
8. Return analysis
9. Inventory and reorder levels
10. Supplier performance

## Objective

To demonstrate practical SQL, relational database design,
data validation and business analysis skills using a realistic
logistics and e-commerce dataset.
